# Nexus AI — Pack complet de contextes agents

> Nexus AI — version documentaire 1.1, 10 octobre 2026. Statut : spécification, pas implémentation.

Ce ZIP est un **dossier documentaire prêt à déposer dans un dépôt Git**, pas une application exécutable. Son entrée unique est `00_START_HERE.md`. Le dossier `ID/idee.md` contient le cahier maître complet, non résumé, enrichi d'un renvoi aux décisions explicites. Les anciens cahiers sont conservés dans `SOURCES_ORIGINALES/`.

**Parcours de l'agent :** `00_START_HERE.md` → `ID/idee.md` → `GOUVERNANCE/` → `ARCHITECTURE/` → `SECURITE/` → `ROADMAP/` → `CONTEXTES_AGENTS/` → `TICKETS/` → implémentation.

**Vérité documentaire :** spécification et hypothèses de développement. Les URL, versions, flags, détails de fournisseurs et conditions doivent être vérifiés au moment de coder ; aucune connexion réelle n'a été testée par ce pack. Les docs spécialisées répètent intentionnellement des portions du maître pour donner du contexte ciblé.
